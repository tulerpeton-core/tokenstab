# TokensTab — desktop app (Windows, Tauri 2)

Калькулятор кредитов Higgsfield: расчёт стоимости генераций, наценка, чек клиенту.

## Как устроено
- `design/App.dc.html` — утверждённый макет (финальная страница холста). Интерфейс приложения берётся прямо из него.
- `tools/build-ui.js` превращает макет в `src/app.gen.js` (добавляет управление окном: перетаскивание, «поверх окон», свернуть, закрыть).
- `src/dc-runtime.js` — маленький движок на Preact, который отрисовывает шаблон макета (`{{…}}`, `sc-for`, `sc-if`, события).
- `src/main.js` — запуск, сохранение расчётов и настроек в `localStorage`, связь с окном Tauri.
- `src-tauri/` — оболочка Tauri: окно 420×800 без рамки, поверх окон.
- Цены — встроенный каталог из разведки 16.10.2026 (`../research/*.json`). Обновление через расширение-сборщик — следующий этап.

## Команды
```
npm install
npm run serve      # проверить интерфейс в браузере: http://127.0.0.1:5174/
npm run dev        # приложение в режиме разработки
npm run build      # релиз: src-tauri/target/release/tokenstab.exe и установщик в src-tauri/target/release/bundle/nsis/
```

Обновили макет? Скопируйте новый `App.dc.html` в `design/` и пересоберите — `build-ui` запускается автоматически перед `dev` и `build`.

## Расширение TokensTab Collector (обновление цен)
Папка `../extension` (в установленном приложении — подпапка `collector` рядом с программой; кнопка «Открыть папку расширения» в разделе «Цены» открывает её).

1. Chrome или Edge → `chrome://extensions` (`edge://extensions`) → включить «Режим разработчика».
2. «Загрузить распакованное» → выбрать папку расширения.
3. Открыть higgsfield.ai и войти. В TokensTab → «Цены» появится «Можно обновить».
4. «Обновить цены» в приложении или в окне расширения. Около 15 минут, вкладка Higgsfield должна оставаться видимой.

Связь: приложение слушает только `127.0.0.1:47821`; запросы с веб-страниц отклоняются.
Проверка связи без браузера: `node tools/fake-extension.js security|hello|wait-command|progress N|verify|catalog`.
