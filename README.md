# TokensTab

Калькулятор кредитов Higgsfield для Windows: считает стоимость генераций (видео, картинки, озвучка), добавляет наценку и делает чек для клиента — PDF, ссылка, Telegram.

- `app/` — приложение (Tauri 2). Сборка и релиз: см. `app/README.md`.
- `extension/` — расширение TokensTab Collector для Chrome / Edge / Brave: по кнопке читает актуальные цены на higgsfield.ai и передаёт их в приложение.
- `docs/` — страница просмотра чека по ссылке (GitHub Pages). Данные чека передаются в самой ссылке после `#` и никуда не сохраняются.

Установщик — в разделе Releases. Установленное приложение само предлагает обновления.
